# PRD — SHOT / Guia Técnico

## Produto
Landing page estática para comercialização do SHOT — Guia Técnico.

## Problema
O visitante precisa entender rapidamente o valor do guia, visualizar a linguagem cinematográfica e saber exatamente como adquirir o PDF.

## Público
Pessoas interessadas em geração de imagens e vídeos por IA que desejam estruturar prompts usando parâmetros cinematográficos.

## Proposta
Transformar decisões técnicas de câmera, lente, enquadramento, abertura e luz em uma linguagem de prompting mais controlável.

## Requisitos funcionais
- Página inicial editorial.
- Página específica do grupo.
- CTAs para WhatsApp.
- FAQ expansível.
- Menu responsivo.
- Navegação por âncoras.
- Imagens locais.
- Sem dependência de React, Vite ou Node para publicação.

## Requisitos não funcionais
- Responsivo.
- Boa legibilidade em mobile.
- HTML semântico.
- CSS organizado por seções.
- JavaScript sem bibliotecas externas.
- Fácil hospedagem em servidor estático.

## Critérios de aceite
- `index.html` abre diretamente no navegador.
- `grupo.html` abre diretamente no navegador.
- Todas as imagens carregam da pasta `images`.
- FAQ funciona.
- Menu mobile funciona.
- Todos os CTAs direcionam ao WhatsApp após configuração do link real.

# SHOT — Guia Técnico — Final

Landing page estática em HTML + CSS + JavaScript puro.

## Páginas
- `index.html` — Home
- `grupo.html` — Fluxo de aquisição pelo WhatsApp

## Estrutura
- `css/style.css` — direção visual e sistema responsivo
- `js/script.js` — menu, scroll reveal, FAQ, navegação e movimento secundário
- `images/` — assets visuais
- `docs/` — SPEC, PRD, workflows, briefing, auditoria de conteúdo e revisão responsiva

## Responsividade
Projeto validado conceitualmente para 360px como stress-test e comportamento touch até 1024px. Desktop editorial a partir de 1025px.

## Movimento
O hero permanece estável. O movimento é reservado ao menu, reveal de conteúdo e parallax muito sutil em imagens secundárias.

## WhatsApp
Substitua `https://chat.whatsapp.com/SEU_LINK_AQUI` pelo link real do grupo.

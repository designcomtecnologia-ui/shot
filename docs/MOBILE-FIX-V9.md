# SHOT V9 — Mobile Fix

## Correções
- Hero mobile reorganizado para eliminar sobreposição entre título, descrição, preço e especificações.
- Hero mobile sem parallax, scale ou transform contínuo.
- Especificações técnicas passam para um bloco compacto em duas colunas.
- Menu mobile reduzido e com painel lateral de largura controlada.
- Removidas setas decorativas dos links do menu mobile.
- Removidos estilos de link herdados que poderiam produzir elementos azuis/sublineados.
- Bloqueio de overflow aplicado ao `html` e `body` durante o menu aberto.
- Menu permite rolagem interna quando necessário.
- `index.html` e `grupo.html` continuam usando o mesmo `script.js` e `style.css`.

## Objetivo
Preservar a direção de arte desktop e criar uma composição mobile própria, legível e estável.
